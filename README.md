MediQue – Hospital OPD Queue Management System

Less Waiting. Better Care.

MediQue is a web-based hospital OPD queue management prototype designed to simplify patient token booking, queue tracking and doctor availability management.

🔗 Live Demo: https://medique-sigma.vercel.app

Features

- Token Booking: Book an OPD token by entering patient details and selecting a department and doctor.
- Queue Tracking: View token details, queue position and estimated waiting time.
- Doctor Availability: View doctor profiles, specializations and availability status.
- Staff Portal: Manage patient queues, call the next patient and update doctor availability.
- Emergency Priority: Give priority to emergency tokens in the patient queue.
- Multilingual Support: Interface available in English, Tamil and Hindi.
- Audio Alerts: Browser-based sound alerts when calling the next patient.

Note

MediQue is currently a front-end prototype. It uses browser Local Storage for data management and does not include a shared backend database or staff login authentication.
